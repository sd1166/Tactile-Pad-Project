# Tactile

## Build

Requires Python 3.10+. From the repo root:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

(or `python -m tactile`)

Use `USE_FAKE_BOARD=1` when no Pico is attached.
